WSL commands (in order)

# 1. Enter the cloned repo
git clone --recurse-submodules git@github.com:ArduPilot/ardupilot.git

cd ardupilot

# 2. Install all ArduPilot build dependencies (~5 min)
Tools/environment_install/install-prereqs-ubuntu.sh -y

# 3. Reload your shell profile (picks up new PATH entries)
. ~/.profile

# 4. Launch ArduPlane SITL
#    First run auto-compiles ArduPlane — takes ~10 min, subsequent runs are instant
#    MAVProxy exposes UDP MAVLink to Windows on port 14550
sim_vehicle.py -v ArduPlane --console --map

Windows commands (after SITL is running)

# In your TEKNOFEST2026 folder, venv activated:

# Option A — fly the real square mission via MAVLink
python scripts/run_square_mission.py

# Option B — visual simulation only (no SITL needed)
python scripts/run_square_simulation.py
